# Русификатор Endless Black Song

Русский перевод. Самой игры здесь нет: нужен уже установленный Endless Black Song.

Сделал его для своей девушки, она попросила. Где-то наверняка есть ошибки и неточности.

Нужна сборка, где `EndlessBlackSong.exe` весит 860776960 байт. На другой версии установщик остановится и ничего не изменит.

## Что нужно

- Windows и установленная игра.
- Установщик `Русификатор Endless Black Song.exe` из раздела Releases. Python для него не нужен.

## Как поставить

1. Закройте игру.
2. Скачайте `Русификатор Endless Black Song.exe` из Releases и откройте его.
3. Если игра установлена через Steam, установщик сам найдёт её папку. Окно выбора откроется только если готовой установки не нашлось. Тогда укажите папку, в которой лежит `EndlessBlackSong.exe`.
4. Подтвердите установку. В вопросе показана папка. Если ответить «нет», ничего не изменится.

Установщик сам игру не запускает. После него откройте игру как обычно. Язык уже будет русский. Открытая в проводнике папка с игрой установке не мешает.

Повторный запуск безопасен: файл игры второй раз не переписывается, файлы перевода обновляются.

Сохранения не меняются.

Проверка файлов в Steam вернёт оригинальную игру. После неё запустите установщик снова.

## Как убрать перевод

Закройте игру. Откройте `Удалить русификатор.exe` в папке с игрой и подтвердите удаление. Он вернёт игру как была и удалится сам. Если на вопрос ответить «нет», ничего не изменится.
